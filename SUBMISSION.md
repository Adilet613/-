# Amigos · Qazaq Loc QA · Decentrathon 6.0

## Состав решения

- Node CLI: locqa.mjs, команды check/apply и опциональный propose.
- Общий engine.js для CLI и сайта.
- Интерактивный сайт для ручной проверки, глоссария, сохранения сессий и ZIP-экспорта.
