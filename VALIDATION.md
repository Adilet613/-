# Проверка поставки SÖZ 1.0

## Выполнено

- 25 Node tests проходят: ARB/CSV, nested ICU, escaped text, other/exact/select, protected tokens, все 11 классов детекции, ручные подтверждения, stale hash, отказ при незакрытых структурных ошибках, совпадение CLI с общим engine.
- JavaScript syntax: engine.js, app.js и locqa.mjs проверены Node.
- DOM-сценарий через LinkeDOM: открытие учебного набора, подтверждение строки, сброс после редактирования, сохранение сессии, переход в глоссарий и ZIP-экспорт.
- Сгенерированный браузерным кодом ZIP прочитан Python zipfile: CRC и состав корректны.
- Полный искусственный пример: все строки подтверждены тестовым проверяющим → ZIP с fixed ARB сформирован, исправленное имя плейсхолдера сохранено. Это программная проверка сценария, не лингвистическая верификация человеком.
- HTTP: index.html, CSS и JS отдаются локальным сервером.
- Проверены HTML-идентификаторы, соответствие импортов и состав ZIP.

## Не выполнено

Полноценный прогон в настоящем браузере и визуальный просмотр экрана не выполнены: установленный Playwright не имел браузерного executable, загрузка Chromium завершилась ошибкой архива. Поведение на целевом GitHub Pages нужно подтвердить после загрузки пользователем.

Не выполнены аудит реальных данных Grand Mobile, ручная лингвистическая проверка, независимый precision, скрытый recall, вызов LLM API и flutter gen-l10n. Искусственный пример не является измерением на данных кейса. Количество тестов не означает 100% coverage.
