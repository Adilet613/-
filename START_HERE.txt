ЭТО ОБНОВЛЕНИЕ SÖZ 1.1. СТАРЫЕ ФАЙЛЫ ДЛЯ ЕГО ЗАПУСКА НЕ НУЖНЫ.

1. Распакуй ZIP.
2. В новом тестовом репозитории нажми Add file → Upload files.
3. Перетащи ВСЕ файлы из архива. Они должны лежать прямо в корне репозитория.
4. Нажми Commit changes.
5. Settings → Pages → Deploy from a branch → main → / (root) → Save.
6. Когда публикация завершится, в Settings → Pages появится ссылка Visit site.
7. Открой именно эту ссылку. Не старый адрес другого сайта.
8. Сразу откроется учебный пример с искусственными строками.
9. Пришли фото результата. Дальше будем менять этот новый проект.

Сайту не нужен терминал, Python или API-ключ. Не загружай исходные игровые данные в публичный репозиторий; выбирай их уже внутри сайта.

Если виден README вместо сайта: проверь, что index.html в корне выбранной ветки, а Pages настроен именно на эту ветку и / (root).
Если видно старое оформление: открой ссылку Visit site в приватном окне и проверь статус последней публикации в Actions.

Для готовой приватной сессии Grand Mobile: открой сайт → Открыть сессию → выбери GRAND_MOBILE_OPEN_IN_SOZ.json. ЭТОТ JSON НЕ ЗАГРУЖАТЬ В GITHUB: он содержит игровые строки. В нём 145 подготовленных находок и 0 ручных подтверждений.
